# Мотивация топ-менеджмента — страница с сохранением в Google Таблицу

## Что где
- Таблица: Мой диск → SmileClinic → Мотивация топов → «Мотивация топ-менеджмента — данные». Все значения — там. Скачать Excel: Файл → Скачать → Microsoft Excel.
- Скрипт `Code.gs` — в этой таблице (Расширения → Apps Script). Читает и пишет значения, проверяет пароль, держит блокировку и счётчик версии.
- Страница `index.html` — на GitHub Pages (репозиторий `smileclinic-motivation`). Чисел и текстов в ней нет: всё приходит из скрипта после ввода пароля.

## Как сохраняется
Любое изменение → статус «есть несохранённые изменения» → через 3 секунды паузы запись (или сразу по кнопке «Сохранить»). Статусы: «сохраняется…», «сохранено ✓ ЧЧ:ММ», «не сохранилось, повторите». «Сохранено» появляется только после ответа скрипта. Если таблицу изменили с другого устройства или руками после того, как ты открыл страницу — появится предупреждение: «Загрузить с сервера» или «Сохранить мою версию поверх».

## История и откат
1. Открой таблицу → Файл → История версий → Смотреть историю версий (или Ctrl+Alt+Shift+H).
2. Справа список версий с временем; клик по версии показывает, какие ячейки изменились (подсвечены).
3. Откатить: выбрать версию → кнопка «Восстановить эту версию» вверху. Страница подхватит её при следующем открытии.
4. Дополнительно лист «Журнал»: по строке на каждое сохранение со страницы — время, номер версии, что именно менялось (например, `grading.weights.financial: 30 → 25`).

## Обновить исходные данные за новый месяц
1. Лист «Данные по месяцам»: вставь строку перед строкой «Поле data.json», заполни: месяц, выручка (БДР «Свод» стр. 3), операционная прибыль (стр. 134), чистая прибыль (стр. 145), к распределению (стр. 154), амортизация (стр. 151), инвестиции (стр. 149), факт выплат 4 ролей (файл «Средняя ЗП», у РОП минус доплата за ЗТЛ).
2. План долголетия — лист «Долголетие», блок под строкой «Месяц / Выручка направления»: добавь строку.
3. Обнови страницу — новый месяц появится в таблицах и в выборе периода.

## Пароль
Хранится в свойствах скрипта (ключ `PASSWORD`). Сменить: Apps Script → Настройки проекта → Свойства скрипта. В коде страницы и в репозитории пароля нет. Браузер запоминает пароль до закрытия вкладки.
